# A股开户指南

一份写给想买 A 股的新手的科普：先讲清交易规则和各类权限，再把佣金、最低 5 元起收和"免五"算明白，最后说怎么挑券商、怎么开户、怎么核对自己到底被收了多少钱。

*本系列只是个人科普，不构成任何投资建议。规则和费率会变，动手前请以交易所、中国结算和你所在券商的最新公示为准，具体方案、费率及适用条件请向券商官方确认。*

*正篇最后校订于 2026 年 11 月 6 日，之后的变化记在 [CHANGELOG](CHANGELOG.md)。*

## 阅读建议

- 完全没炒过股：按顺序读一到三章，先把规则和成本搞明白。
- 已经有账户，只想知道自己是不是被多收了钱：直接看 **三（佣金与免五）** 的算账部分和 **六** 里的"交割单核对"。
- 要开新户或转户：看 **四**、**五**、**六**。
- 只关心某个权限能不能开：看 **二**。
